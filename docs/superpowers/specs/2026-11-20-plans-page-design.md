# 制定計畫頁（/plans）設計規格與評估

日期：2026-11-20

## 1. 需求情境

總名單與每日任務解決了「記人」與「今天找誰」，但還沒有地方承接**群體層級的策略**：

> 「有些人名單上的人不讀不回，我計畫用發廣告的方式，重新去聯絡他們。」

這類想法的共通結構是：**觀察到某種現象 → 對一群人 → 用某種方法 → 在一段时间内 → 執行，然後想知道有没有用**。本頁把这条链路做成一张「計畫卡」。

## 2. 資料模型

新表 `plans`（比照 contacts 的 JSON 欄與 userId 預留慣例）：

| 欄位 | 意義 |
| --- | --- |
| name | 計畫名稱（必填），如「不讀不回重啟計畫」 |
| insight | 現象／洞察，如「不讀不回」 |
| method | 方法／管道，如「發廣告」 |
| content | 執行內容（廣告素材方向、話術、預算備註…） |
| audience | 圈選對象：contacts.id JSON 陣列 |
| startDate / endDate | 執行期間（可空＝尚未排定／無限期） |
| status | planning（構想中）→ active（執行中）→ done（已完成） |

決策：audience 用 JSON 陣列而非關聯表——圈選是「一次拍板的名單快照」，不需要逐列 metadata；與 contacts.completedStages 同款手法，避免多一張表與 join 成本。

## 3. 評估自動算（「有沒有效」不靠手動打勾）

計畫的成效訊號复用既有**跟進紀錄時間軸**：執行期間內，圈選對象中有任何一筆跟進紀錄 ＝ 已被重新接觸。後端在 `GET /api/plans` 以純函數 `shared/utils/planEval.ts` 對每個計畫算出：

- **audienceCount**：圈選人數
- **reached / rate**：期間內已重新接觸人數與比例（進度條）
- **coverage**：有建檔聯絡管道的人數（發廣告／批量訊息前先看這個——沒有管道的人只能靠平台受眾匹配觸及）
- **stalled**：目前仍停擺的人數（逾期、或最後跟進超過 30 天、或從未跟進）——「不讀不回」的資料代理
- **silent14**：超過 14 天沒聯絡的人數（期間内冷掉的人，收尾覆核用）

圈選彈窗的「不讀不回 +N」預設即取 `isStalled` 判定，讓使用者一鍵圈出痛點人群。

## 4. 頁面設計

- 導覽列新增「制定計畫」（PAGES 常數自動帶入）。
- **計畫卡清單**：每張卡＝手繪框（RoughFrame／RCard），呈現狀態徽章（構想中 gray／執行中 yellow／已完成 green）、現象螢光標記、方法徽章、執行期間、四項評估數字、重新接觸進度條（tabular-nums，符合 number-tabular 規範）。
- **狀態流轉**：卡上按鈕一鍵 開始執行 → 標記完成，只走 PATCH，不另開窗。
- **新增／編輯**：RDialog（PlanEditor）——名稱（必填）、現象、方法（RCombobox 建議「發廣告／LINE 訊息／IG 限動／打電話／見面／群發貼文」，可自行新增）、執行內容 textarea、起訖日期、圈選對象（預設鈕：不讀不回／未破題／全部 ＋ 勾選清單 r-scroll，顯示每人停擺狀態）。
- **表單體驗**（ui-ux-pro-max ux 檢索結論）：送出時按鈕 loading＋禁用（submit-feedback）；驗證錯誤 role="alert" 顯示於表單頂部並 focus（error-summary）；成功 flash toast 比照全站。
- **刪除**走 useConfirm 全域確認框（destructive 確認慣例）。
- **空狀態**：給訊息＋「擬第一个計畫」動作（empty-state 規範）。
- 樣式全部走既有手繪語彙與色 token（--paper/--ink/--marker 等），亮暗两用；進度條只用 transform/width on load，不與 reduced-motion 衝突（全域規則已覆蓋）。

## 5. 方法評估（對「發廣告重啟不讀不回」這個計畫本身）

**可行性**：可行，但要把它看成「暖機」而不是「轉換」。廣告的強項是低成本同時接觸大量冷名單、且不打擾關係（不讀不回的人最怕的是再一條私訊）；弱項是觸及後的承接仍要回到一對一。

**評估面板對應的風險檢查**：

1. **觸及面**（coverage）：圈選人群有建檔 LINE/IG/FB 的比例。比例低 → 廣告只能靠平台受眾比對（相似受眾），觸及更不可控 → 先把名單補齊再投。
2. **停擺深度**（stalled、silent 分佈）：全部逾期 30 天以上屬「冷群」，廣告適合；若很多人只是這週才逾期，改用一般跟進即可，發廣告是浪費。
3. **名冊上傳合規**：把名單上傳作廣告自訂受眾，涉及個資與平台條款（Meta／Google 要求使用者同意與來源合法）。名單含姓名＋手機號時務必先確認合規，否則改用「興趣＋行為」式投放或相似受眾，不直接上傳名單。
4. **成效判讀**（reached rate）：以 2–4 週為一輪，收尾時看「重新接觸率」；廣告帶來的回應通常以週計，期間太短會誤判無效。

**建議預設**：先對「不讀不回 ≥30 天」這群發一則低承諾度的軟性內容（生活向限動／貼文，不賣產品），兩週後看 reached 再決定第二輪加不加私訊。
